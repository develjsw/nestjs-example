### 팩토리 패턴 ( Factory Pattern )

- 팩토리 패턴이란 ? :
  - 객체 생성 로직을 캡슐화하여 객체 생성 방식을 다양하게 제공하는 디자인 패턴


- 목적 :
  - 객체 생성 로직을 캡슐화하여 클라이언트 코드와 생성 로직 간의 결합도를 낮추는 것
  - 객체 생성의 유연성을 확보하고 코드의 확장성을 높이는 것


- 사용 시점 :
  - 생성할 객체의 구체적인 클래스가 런타임에 결정되어야 할 때
  - 객체 생성 로직이 복잡하여 이를 분리하고 싶을 때
  - 객체 생성이 코드 중복을 유발하거나 변경에 취약할 때


- 구조 : 
  - Product : 생성될 객체의 인터페이스 또는 부모 클래스
  - ConcreteProduct : Product 를 구현한 구체적인 클래스
  - Creator : 객체 생성을 위한 팩토리 인터페이스
  - ConcreteCreator : 객체 생성 로직을 구현하는 구체적인 팩토리 클래스
