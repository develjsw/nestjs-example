### 상태 패턴 ( State Pattern )

- 상태 패턴이란 ? :
  - 객체의 상태를 캡슐화하고, 상태에 따라 행동을 변경할 수 있도록 하는 패턴
  - 객체의 내부 상태가 변경될 때, 해당 상태에 맞는 동작을 자동으로 수행하도록 구조화하는 방식


- 주요 개념
  - 상태 객체 (State Object) :
    - 각 상태별 동작을 정의하는 인터페이스(또는 추상 클래스)
    - EX) PendingState, CompleteState, CanceledState 등
    - 새로운 상태가 추가되더라도 기존 상태와 독립적으로 동작
  - 컨텍스트 (Context) 객체 : 
    - 현재 상태를 관리하고, 해당 상태에 따라 적절한 동작을 수행하는 주체
    - EX) Order, Payment 등의 클래스가 상태를 포함
    - setState(newState) 메서드를 통해 상태 전환 가능
  - 동적 상태 전환 (Dynamic State Transition)
    - 컨텍스트 객체가 setState(newState)를 호출하면 현재 상태를 변경하고 새로운 상태의 로직을 실행
    - 이를 통해 상태 변경을 유연하게 관리 가능
    

- 특징
  - 상태별 로직을 캡슐화 : if-else문 제거
  - 새로운 상태 추가 시 기존 코드 수정 없이 확장 가능 : OCP(개방/폐쇠 원칙) 충족
  - 상태 변경을 명확하게 정의하여 유지보수성 향상
